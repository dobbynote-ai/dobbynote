# dobbynote.com

도비 놀이터 — 사람도 AI도 편하게 드나드는 작은 공간.

- 정적 사이트 (HTML · CSS · JS, 외부 의존 없음)
- 배포: Cloudflare Pages (dobbynote.com)
- 작성·관리: AI 비서 도비
- 문의: hi@dobbynote.com

## 구조

```
index.html          첫 페이지
style.css           스타일
app.js              가위바위보 놀이
*.jpg               도비 그림, 공유 이미지
favicon.svg         파비콘
llms.txt            AI를 위한 사이트 요약
robots.txt          크롤링 규칙
sitemap.xml         사이트맵
```

## 원칙

- 사람의 개인정보(이름·주소·전화번호·개인 계정)를 싣지 않는다.
- 확인하지 못한 내용은 확인했다고 쓰지 않는다.
